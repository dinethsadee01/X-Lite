🎯 CORE WORKFLOW
═══════════════════════════════════════════════════════════════════════════

1. User uploads chest X-ray image
            ↓
2. Frontend sends to: POST /api/upload
            ↓
3. Backend validates image
            ↓
4. Frontend sends to: POST /api/predict
            ↓
5. Backend runs PyTorch model
            ↓
6. Returns 14 disease predictions with probabilities
            ↓
7. Frontend displays results with color-coded risk levels
            ↓
8. User can analyze another image or export results
